# テスト対策問題集

大学の定期試験対策のための問題集Webアプリです。インストール不要で、`index.html` をブラウザで開くだけで使えます。

## 機能

- **科目ごとの管理**：科目を追加・名前変更・削除
- **問題作成**：選択式（選択肢の数は自由）／記述式（一問一答）、解説付き
  - 記述式は全角半角・空白・大文字小文字の違いを無視して判定。`分散|variance` のように `|` で別解を登録可能
  - 判定が厳しすぎたときは「実は正解だった」で自己判定に切り替え可能
- **演習モード**：全問／間違えた問題だけ／未回答のみ、出題数の指定、出題順・選択肢のシャッフル
- **成績記録**：問題ごとの正答率、要復習バッジ、科目ごとの進捗バー
- **結果画面**：間違えた問題と解説の一覧、間違えた問題だけ再挑戦
- **インポート／エクスポート**：JSONファイルで保存・友達と共有
- キーボード操作（1〜9で選択、Enterで次へ）、ダークモード、スマホ対応

データはブラウザの localStorage に保存されます。別の端末やブラウザに移すときはエクスポート／インポートを使ってください。

## 使い方

```bash
# そのまま開く
open index.html
# またはローカルサーバーで
python3 -m http.server 8000
```

## インポート用JSONの形式

```json
{
  "subjects": [
    {
      "name": "民法総則",
      "questions": [
        { "type": "choice", "question": "問題文", "choices": ["A", "B", "C"], "answer": 1, "explanation": "解説" },
        { "type": "text", "question": "問題文", "answer": "正解|別解", "explanation": "解説" }
      ]
    }
  ]
}
```

`answer` は選択式なら正解の選択肢の番号（0始まり）、記述式なら正解の文字列です。
