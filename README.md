# テスト対策問題集

大学の定期試験対策のための問題集Webアプリです。ビルド不要で、HTML/CSS/JavaScript だけで動きます。

## 機能

- **科目ごとの管理**：科目を追加・名前変更・削除
- **問題作成**：選択式（選択肢の数は自由）／記述式（一問一答）、解説付き
  - 記述式は全角半角・空白・大文字小文字の違いを無視して判定。`分散|variance` のように `|` で別解を登録可能
  - 判定が厳しすぎたときは「実は正解だった」で自己判定に切り替え可能
- **AIで問題を自動作成**：授業ノートの貼り付けや、PDF・画像・テキストの資料から Claude が問題を作成。生成結果を確認し、選んだ問題だけ追加
- **試験日カウントダウンと学習プラン**：科目ごとに試験日を設定すると「試験まであと○日」と「今日の目標問題数」を表示。今日の分は「間違えた問題 → 未回答 → その他」の順に出題。今日解いた数と連続学習日数も表示
- **画像付きの問題**：問題と解説に図やグラフを添付（ファイル選択か、テキスト欄に貼り付け）。自動で縮小して保存
- **数式表示**：`$x^2$`（文中）や `$$\int_0^1 f(x)\,dx$$`（独立）のように LaTeX で書くと数式で表示（KaTeX）。入力中にプレビュー
- **ログインと端末間同期**：Google アカウントでログインすると、スマホとPCなどで問題・成績・学習記録を同期（Firebase）
- **演習モード**：全問／間違えた問題だけ／未回答のみ、出題数の指定、出題順・選択肢のシャッフル
- **成績記録**：問題ごとの正答率、要復習・習得バッジ、科目ごとの進捗バー
- **インポート／エクスポート**：JSONファイルで保存・友達と共有
- キーボード操作（1〜9で選択、Enterで次へ）、ダークモード、スマホ対応

データはブラウザの IndexedDB に保存されます（以前の版の localStorage のデータは自動で引き継ぎます）。

## 起動方法

ログイン・同期を使う場合は Web サーバー経由で開く必要があります（`file://` では Google ログインが使えません）。

```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

### GitHub Pages で公開する（スマホからも使える）

1. GitHub のリポジトリで **Settings → Pages** を開く
2. Source を「Deploy from a branch」、ブランチを `main`（フォルダは `/`）にして保存
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになります

## AI問題生成の設定（Claude API）

1. [Claude Console](https://platform.claude.com/) でアカウントを作り、APIキーを発行（従量課金です）
2. アプリの **⚙️ 設定 → AI問題生成** にキーを入力して保存
3. 科目ページの **✨ AIで作成** から、ノートを貼り付けるか資料ファイルを選んで生成

- 生成のたびに料金の目安（米ドル）を表示します。⚙️ 設定で今月・累計・履歴を確認できます（端末ごとの記録）
- APIキーはその端末のブラウザにだけ保存され、エクスポートや同期には含まれません。共用PCでは保存しないでください
- 資料は Anthropic の API に送信されます
- モデルは Opus 5.5（高品質）／Sonnet 5.5／Haiku 5.5（安い・速い）から選べます
- AIの問題は誤りを含むことがあります。追加後に「編集」から直せます

## ログイン・同期の設定（Firebase）

自分専用の Firebase プロジェクトを無料枠で作って使います。

1. [Firebase コンソール](https://console.firebase.google.com/) でプロジェクトを作成
2. **Authentication → Sign-in method** で「Google」を有効にする
3. **Authentication → Settings → 承認済みドメイン** に、アプリを開くドメイン（例: `<ユーザー名>.github.io`）を追加（`localhost` は最初から入っています）
4. **Firestore Database** を作成し、**ルール**を次のように設定して公開（自分のデータは自分しか読み書きできない設定）

   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /users/{uid}/{document=**} {
         allow read, write: if request.auth != null && request.auth.uid == uid;
       }
     }
   }
   ```

5. **プロジェクトの設定 → マイアプリ** で「ウェブアプリ」を追加し、表示される `firebaseConfig` をコピー
6. アプリの **⚙️ 設定 → ログインと端末間同期** に貼り付けて「設定を保存して接続」→「Googleでログイン」
7. 他の端末でも同じ firebaseConfig を貼り付けて、同じ Google アカウントでログイン

同期のしくみと注意点：

- 科目ごとに「新しく更新された方」が採用されます。2台で同時に同じ科目を解くと、片方の成績が上書きされることがあります
- 画像が多すぎる科目（1科目あたり約0.9MB超）は同期できません。画面上部に警告が出ます

## インポート用JSONの形式

```json
{
  "subjects": [
    {
      "name": "民法総則",
      "examDate": "2027-01-20",
      "questions": [
        { "type": "choice", "question": "問題文", "choices": ["A", "B", "C"], "answer": 1, "explanation": "解説" },
        { "type": "text", "question": "$\\sqrt{4}$ は？", "answer": "2|２", "explanation": "解説" }
      ]
    }
  ]
}
```

`answer` は選択式なら正解の選択肢の番号（0始まり）、記述式なら正解の文字列です。`examDate`・`image`・`explanationImage`（data URL）は省略できます。
